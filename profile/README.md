## EoL3D

A dataset of 66 end-of-life desktop computers taken apart by hand, one step at a time: scanner images with instance
masks, part states and removal relations, 3D reconstructions, question-answer pairs, operator video and robot
demonstrations.

- **Website**: <https://eol3d.github.io> (what the data is, an interactive teardown, benchmark results)
- **Data**: <https://huggingface.co/datasets/ChangChrisLiu/E3D-Desktop-Disassembly>
- **Code**: [EoL3D/EoL3D](https://github.com/EoL3D/EoL3D) (detection kit, question-answering tools, depth scorer, point-cloud tools)
- **Annotation tool**: [DataLabelToolForEoLDesktopDisassembly](https://github.com/ChangChrisLiu/DataLabelToolForEoLDesktopDisassembly) (the desktop tool the annotations were made with, and the exporters)
